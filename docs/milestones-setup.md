# ミッション進捗管理テンプレート — セットアップガイド

`docs/milestones-template.xlsx` を Google Sheets にインポートして運用するための手順書です。

---

## 1. Google Sheets へアップロード

2つの方法があります。初回は **A (手動)** が最速、以降テンプレート再生成時は **B (スクリプト)** が便利です。

### A. 手動アップロード (所要 1分、初回推奨)

1. [Google Drive](https://drive.google.com/) を開く
2. `[新規] → [ファイルのアップロード]` → `docs/milestones-template.xlsx` を選択
3. アップロードされたファイルを右クリック → `[アプリで開く] → [Google Sheets]`
4. 自動的に `.gsheet` 形式に変換される

> 💡 Drive 上で右クリック → `[Google Sheets として開く]` でも同じ結果になります。

### B. スクリプトで自動アップロード (所要 初回5分、以降10秒)

テンプレートを改訂して再生成するたびに Sheets へ反映させたい場合、`scripts/upload-milestone-to-gsheets.py` を使います。同名のシートがあれば **上書き** (URL据え置き)、なければ新規作成。

**初回のみ** (`uv` と `gcloud` が必要):

```bash
# 1. (未導入なら) uv をインストール
#    macOS:  brew install uv
#    他:     curl -LsSf https://astral.sh/uv/install.sh | sh

# 2. (未導入なら) Google Cloud SDK をインストール
#    macOS:  brew install --cask google-cloud-sdk
#    他:     https://cloud.google.com/sdk/docs/install

# 3. Google アカウント認証 (Drive スコープ付き) — ブラウザが開く
gcloud auth application-default login \
  --scopes=https://www.googleapis.com/auth/drive,openid,https://www.googleapis.com/auth/userinfo.email
```

Python ライブラリは `uv` がスクリプト初回実行時に自動インストール (PEP 723 インラインメタデータ)。`pip install` 不要。

**アップロード実行**:

```bash
# 通常: 同名シート上書き (or なければ新規)
./scripts/upload-milestone-to-gsheets.py

# 特定のDriveフォルダに置きたい
./scripts/upload-milestone-to-gsheets.py --folder-id <DRIVE_FOLDER_ID>

# 毎回新規作成
./scripts/upload-milestone-to-gsheets.py --force-new
```

成功時は `created: https://docs.google.com/spreadsheets/d/...` が出力されます。

テンプレート修正 → 運用フロー:

```bash
python3 scripts/build-milestone-template.py      # xlsx 再生成
./scripts/upload-milestone-to-gsheets.py         # Sheets へ反映 (同URL)
```

## 2. 必須セットアップ (所要 3分)

インポート後、Google Sheets 独自機能を有効化します。これをやらないとチェックボックス編集ができません。

### A. 完了列をチェックボックスに変換

各ミッションシート (`2026夏_モンゴル`, `2026秋_ネパール`, `テンプレート`) で:

1. **F列** の `F8:F500` をドラッグ選択
2. メニュー: `[挿入] → [チェックボックス]`
3. 既存の `TRUE / FALSE` 値が自動でチェック状態に変換される

### B. 日付はダブルクリックでカレンダーから選択

A列 (日付) と F3 (出発日) には **日付バリデーション** が設定済み。セルをダブルクリックするだけでカレンダーピッカーが開き、**キーボード入力不要** で日付を選べます。

- セル選択時に右側に 📅 アイコンが出る → クリック / ダブルクリック
- 年月を切替えて日付をクリック → 自動入力
- 無効な日付を手入力しようとすると警告が出る

バリデーションが外れている場合は再設定:
1. `A8:A500` を選択
2. `[データ] → [データの入力規則]` → `[+ ルールを追加]`
3. 条件: `有効な日付` → 完了

### C. 担当ドロップダウンの動作確認

E列の任意のセルをクリック。`メンバー` シートの名前がドロップダウン表示されれば OK。
表示されない場合は再設定:

1. `E8:E500` を選択
2. `[データ] → [データの入力規則]`
3. 条件: `プルダウン (範囲から)` → `=メンバー!A5:A30`

### D. (任意) 条件付き書式の確認

データメニュー → 条件付き書式で以下4つのルールが存在することを確認:

| 条件 | 背景色 | 文字 |
|---|---|---|
| 完了 (F=TRUE) | 灰 | 取り消し線 |
| 期限超過 | 赤 | 太字 |
| 今日 | 金 | 太字 |
| あと3日以内 | 橙 | 通常 |

> xlsx → Sheets 変換で条件書式が消えている場合、[書式] → [条件付き書式] から下記数式で再追加できます(4つとも先頭行 A8 を基準):
>
> - 完了: `=$F8=TRUE`
> - 期限超過: `=AND($A8<>"",$A8<TODAY(),$F8<>TRUE)`
> - 今日: `=AND($A8=TODAY(),$F8<>TRUE)`
> - あと3日以内: `=AND($A8<>"",$A8>TODAY(),$A8-TODAY()<=3,$F8<>TRUE)`

## 3. メンバー共有

### 運営メンバー (編集可)

1. 右上 `[共有]` ボタン
2. 編集者として Google アカウントを個別追加
3. 通知メールで URL がメンバーに届く

### リンク共有方針

- **公開しない** (URL を持つ全員が閲覧可能にする設定 = 避ける)
- URL はメンバー間の **Discord / Slack / Signal** 等のクローズドチャネルでのみ共有
- URL を知らない人は見られない = シンプルだが実用十分な保護

### (任意) シートを保護して誤編集防止

公式サイトが将来このシートを読む場合、誤編集を防ぐため:

1. 保護対象シート (例: `2026夏_モンゴル`) のタブを右クリック → `[シートを保護]`
2. `[権限を設定]` → 編集可能ユーザーを限定 (例: 代表・副代表のみ)

## 4. 新規ミッションの作成

1. 画面下のタブ `テンプレート` を右クリック → `[コピーを作成]`
2. 新タブ名を `年_季節_地域` 形式に変更 (例: `2027春_ネパール`)
3. **F3 の「出発日」セルをダブルクリック** → カレンダーから日付選択 → D-day 自動計算
4. タスクを上から追加:
   - **日付** (必須、期限。**ダブルクリックでカレンダー**)
   - **カテゴリ** (ドロップダウン: 書類 / 会計 / 物品 / 広報 / 当日運営 / その他)
   - **タスク** (簡潔に。10-30字推奨)
   - **担当** (ドロップダウン)
   - **完了** (F列チェックボックス)
   - **優先度** (高 / 中 / 低)
   - **備考・詳細** (自由記入。サブステップは `☐` / `☑` で行頭に並べると §6 の Apps Script でクリック切替可能)

参考: 既存の `2026秋_ネパール` シートは防災教育ミッション例、`2026夏_モンゴル` は植林ミッション例。カテゴリ配分・タスク粒度の参考に。

## 5. 運用のコツ

### フィルタ
1. ヘッダー行を選択 → `[データ] → [フィルタを作成]`
2. 各列のフィルタボタンで絞り込み:
   - 担当で絞り込み → 自分の担当だけ表示
   - カテゴリで絞り込み → 会計だけ / 物品だけ

### ソート
- 日付列を昇順ソートで期限順に並べる (デフォルト状態が既にそう)

### コメント
- セル右クリック → `コメント` で特定タスクに議論スレッドを残せる

### 修正履歴
- `[ファイル] → [版の履歴] → [版の履歴を表示]` で過去の状態を確認・復元可能

### モバイル編集
- Google Sheets **モバイルアプリ** でほぼ同じUIが使える
- チェックボックスのタップ、担当ドロップダウン、日付ピッカーも標準対応
- 別アプリを入れる必要なし

## 6. H列サブタスクのサイドバー管理 (Apps Script)

Apps Script のサイドバー機能で、H列 (備考・詳細) のサブタスクを **追加 / 編集 / 削除 / 完了切替** すべてクリック操作で行えます。タスク行を選択するとサイドバーが自動で対応するサブタスクに切り替わります。

### 6-A. H列のサブタスク記法

H列のセルに、1行1サブタスクで `☐` (未完了) または `☑` (完了) で始まる行を書きます:

```
☑ 会場予約
☑ 資料作成
☐ メンバー連絡
☐ リハーサル
```

下の Apps Script をインストールすれば、サイドバーから直接編集できるので手書きは不要です。

### 6-B. インストール (1回限り、5分)

1. Google Sheets で対象のシートを開く (`.XLSX` 表示の場合は先に `[ファイル] → [Google スプレッドシートとして保存]`)
2. メニュー [拡張機能] → [Apps Script] (新しいタブで Apps Script エディタが開く)
3. 既存の `function myFunction() {}` を全部削除
4. リポジトリの `scripts/google-apps-script-subtask-toggle.gs` の全文をコピー&ペースト
5. Cmd+S で保存 (プロジェクト名は任意。例: `Axis Subtask Sidebar`)
6. Sheets タブに戻ってリロード (Cmd+R) → 上部メニューに `Task Management` が出現
7. 初回 [サイドバーを開く] 実行時に「権限の確認」 → [詳細] → [(プロジェクト名) に移動] → [許可]

> 個人 Apps Script なので Google 審査が無く「未確認」と表示されますが、本人アカウントの本シート内でしか動作しません。コードは50行程度の純粋な spreadsheet 操作のみ。

### 6-C. 使い方

1. メニュー [Task Management] → [Open Sidebar] (右側にパネル出現、以後セッション中は開いたまま)
2. ミッションシートでタスク行のセルを **クリック** (どの列でもOK、自動で D列のタスク名と H列のサブタスクを取得)
3. サイドバーに以下が表示:
   - **ヘッダー**: 日付 / 担当 / 優先度 / 親タスクの完了状態
   - **進捗バー**: `3/5 (60%)` など
   - **サブタスク一覧**: 各行にチェックボックス + 編集可能なテキスト + 🗑 削除ボタン
   - **追加フォーム**: テキスト入力 + [+ サブタスク追加] ボタン
   - **新規タスク行を追加** (下部・折り畳み): 日付・カテゴリ・タスク・担当・優先度・備考フォーム
4. 操作:
   - **完了/未完了切替** → チェックボックスをクリック
   - **テキスト編集** → サブタスクのテキスト欄をクリック → Enter または別箇所クリックで保存
   - **削除** → 🗑 ボタン (確認ダイアログあり)
   - **新規追加 (サブタスク)** → 下の入力欄に文字 → Enter または [+ サブタスク追加]
   - **新規タスク行追加** → 下部の [+ 新規タスク行を追加] をクリックしてフォームを展開

別のタスク行をクリックすれば、サイドバーが自動で切り替わります (約0.7秒以内)。

### 6-D. 新規タスク行追加フォーム

サイドバー下部の [+ 新規タスク行を追加] ボタンを開くと、以下を入力できる:

| フィールド | 入力方式 | 備考 |
|---|---|---|
| 日付 | カレンダー (`<input type="date">`) | デフォルト = 今日。空欄も可 |
| カテゴリ | ドロップダウン | 書類 / 会計 / 物品 / 広報 / 当日運営 / その他 |
| タスク **必須** | テキスト | この欄が空だと送信できない |
| 担当 | ドロップダウン | 現在のミッション用メンバー (メンバー_モンゴル または メンバー_ネパール) を自動取得 |
| 優先度 | ドロップダウン | 高 / 中 / 低 (デフォルト 中) |
| 備考・詳細 | テキスト (複数行) | サブタスクは ☐ 行で記述 |

[+ 追加] を押すと:
1. 入力した日付に応じて、**既存の日付順を保ったまま正しい位置に行が挿入** される (例: 5/15 を入れると 5/10 と 5/20 の間に入る)
2. F列 (完了) は FALSE で初期化、B列 (D-N) の式と日付フォーマットも自動付与
3. 新規行のタスク名セルにアクティブセルが移動 → サイドバーが新規行に自動切替

日付を空欄で送信した場合は末尾に追加されます。

### 6-E. 補足

- F列 (完了) は親タスク全体のチェック。サイドバーのチェックボックスは H列内の各サブタスク用。
- 進捗率 (画面上部) は F列基準。サブタスクの個別進捗はサイドバー上の進捗バーで確認。
- サブタスクごとに独立した期限・担当を持たせたい場合は、H列ではなく **1サブタスク = 1行 (別タスク行)** で運用 (タスク名を `親名: 子項目` の命名規則)。

## 8. トラブルシュート

| 現象 | 原因 | 対処 |
|---|---|---|
| 担当ドロップダウンが出ない | データ入力規則の範囲 | §2-B 参照 |
| D-N が文字列で出てくる | 日付列に文字が混ざった | A列のセル書式を「日付」に再設定 |
| 進捗率が計算されない | F列がチェックボックス化前 | §2-A 実施 |
| 行の色が変わらない | 条件付き書式欠落 | §2-C 参照 |
| モバイルで色が薄い | ダークモード設定 | アプリ設定で「ライト」に |
